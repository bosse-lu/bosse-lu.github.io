Débloquer une évaluation ou ouvrir une étape

  1. Le plus simple : demandez-le à Claude, par exemple « débloque l'évaluation orale du prétérit pour la 5e C », « ouvre Fill in the note pour la 5e F » ou « ouvre le dialogue 2 pour la 4e E ». La mise à jour est en ligne une à deux minutes plus tard.
  2. Vous-même, sur GitHub : ouvrez le fichier classes.json du dépôt, cliquez sur le crayon, puis modifiez la classe voulue :
    • "open": ["note", "ed"] = étapes ouvertes (note Fill in the note, ed Les sons de -ed, so Can you explain?, bus Blame the bus!, excuse Recap: Excuse Lab) ; "open": [] = tout verrouillé ;
    • "groups" = codes de groupe de la classe qui imposent un niveau (★★ ou ★★★). Les élèves sans code de groupe gardent le niveau libre. Pour créer ou changer un groupe, demandez-le à Claude ;
    • "parts": {"note": {"dialogues": [1]}} = dans Fill in the note, seul le dialogue 1 est ouvert (sans cette ligne, toute l'étape est ouverte) ;
    • "evals": ["ed-final"] = évaluation orale du prétérit débloquée ; "evals": [] = tout verrouillé.
    Enregistrez avec « Commit changes ».

Bon à savoir

  • L'élève entre le code de sa classe une seule fois par appareil, sur la page de la séquence ou devant l'évaluation. S'il change d'appareil, il le retape.
  • Les étapes et les évaluations sont verrouillées par défaut, y compris pour un élève sans code de classe : il ne voit que ce que vous avez ouvert pour sa classe. L'espace « Pour aller plus loin… » (News, foot) reste toujours libre.
  • Il n'y a pas de comptes élèves : la progression reste sur l'appareil. C'est un verrou pédagogique, pas une protection forte.
