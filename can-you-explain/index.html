Notes pour le professeur
  • La page suit le diaporama de la séance 2, avec ses images : Warm-up · revision (3 images de la séance 1), So, let's recap (animation lancée par l'élève : les billets apparaissent, il choisit I'm late / I was absent / Can I…?, puis les mots rouges s'inscrivent), Make excuses (avec because, déjà connu), Look and think (réflexion sur la langue : les deux phrases inversées et colorées, quatre questions, puis la règle formulée), Recreate the situation (3, avec la boîte mystère qui cache because ou so), Linking words (texte à trous : and, but, because, so, pour montrer que so appartient à la famille des mots qui relient deux propositions), puis le jeu.
  • Consignes en anglais. Groupe ★ (et niveau libre) : traduction française affichée dessous ; ★★ : bouton FR pour l'afficher ; ★★★ : anglais seul.
  • Le jeu : 25 secondes par carte, score, pastilles verte / jaune / rouge (1, 2, 3 points). 1er temps à l'écrit : ★ mots à remettre dans l'ordre, ★★ mots + erreurs, ★★★ rédiger la phrase. 2e temps à l'oral : ★ mots dans le désordre avec une erreur, ★★ mots + erreurs, ★★★ l'image seule ; l'élève dit la phrase (il peut s'enregistrer), puis la vérification sonore fait entendre le modèle (voix anglaise du navigateur) et il valide.
  • Code couleur des diapos : cause en vert, conséquence en rouge, mot de liaison souligné. La phrase suit l'ordre des images : billet puis image → conséquence + because + cause (I'm late because I overslept) ; image puis billet → cause + so + conséquence (I overslept, so I was absent). Dans Make excuses, la 2e excuse cache so dans une boîte mystère ❓ : l'élève le découvre en manipulant, puis l'étape 4 fait formuler la règle.
