Notes pour le professeur
  • La page reprend votre diaporama de la séance 2, dans l'ordre : Warm-up · revision, So, let's recap (les billets apparaissent, l'élève dit I'm late / I was absent / Can I…, puis les mots rouges s'inscrivent), Make excuses, Cause and consequence (les blocs se construisent comme sur la diapo), Recreate the situation et Time to manipulate – the game. La correction des exercices A et B reste sur papier.
  • Code couleur des diapos conservé : cause en vert, conséquence en rouge, mot de liaison souligné. Les deux formes sont acceptées : I'm late because I overslept et I overslept, so I'm late.
  • Le jeu : chrono de 15 secondes, score, pastilles verte / jaune / rouge (1, 2, 3 points). 1er temps à l'écrit : ★ mots à remettre dans l'ordre ; ★★ mots + erreurs (étiquettes pièges) ; ★★★ rédiger la phrase. 2e temps à l'oral : ★ mots dans le désordre avec une erreur, ★★ mots + erreurs, ★★★ l'image seule ; l'élève dit la phrase (il peut s'enregistrer), puis la vérification sonore lui fait entendre le modèle et il valide lui-même.
  • Le niveau vient du code de groupe (★★ ou ★★★) ; avec le code de classe, l'élève choisit. La vérification sonore utilise la voix anglaise du navigateur (pas d'enregistrement de votre audio pour ces phrases). Les illustrations du manuel sont remplacées par des pictogrammes, avec un indice en français.
